# Paper-reference values

`locked_results.yaml` transcribes aggregate values explicitly reported in the supplied manuscript.

These files are **reference-only**. They are useful for:

- checking arithmetic claims such as percentage reductions;
- checking that figure/table generation code does not silently alter published values;
- documenting which values came from the paper rather than from this generated implementation.

They are **not** a substitute for the origin–task–seed immutable record archive described by the manuscript. Aggregate tables cannot reconstruct paired confidence intervals, individual failures, raw costs, solver logs, or seed-level variability.
